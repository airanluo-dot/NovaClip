# Design system

NovaClip uses Windows App SDK controls and theme resources: Mica, system caption buttons, NavigationView, CommandBar, InfoBar, ContentDialog, native focus visuals and high-contrast behavior.

Spacing tokens are 4, 8, 12, 16, 24 and 32. Pages remain transparent over Mica. Cards are used only for meaningful grouping. The browser media pane is 340 px on wide layouts and moves below the browser below 900 px.
